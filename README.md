# StudyFlow (Marcos Vinícius/ 37024348)

SPA de organização de estudos feita com **React + Vite + React Router**.

## Propósito
Permitir que estudantes anotem tarefas e acompanhem o que já foi concluído, navegando entre seções sem recarregar a página.

## Por que React?
- **Componentização:** `Navbar` e `TaskItem` são componentes reutilizáveis.
- **Estado e eventos:** `useState` atualiza a tela a cada ação do usuário.
- **SPA:** o React Router troca de seção sem recarregar a página.

## Seções
- **Início:** resumo de tarefas concluídas.
- **Tarefas:** adicionar, concluir e remover tarefas.
- **Contato:** formulário simples.

## Como executar
```bash
npm install
npm run dev
```
